   - Reconciled §5.3, §6.1, and §6.2 into three uniform, non-contradictory result categories:
     - **C-ABI Error (`rc != BORNO_OK`):** Output struct fields are NEVER inspected; cached state is untouched; UI is not falsely altered; members are freed via `borno_process_result_free_members(&res)`; key is consumed (`filterAndAccept()`) to prevent leaking raw keystrokes during engine errors.

## 1. Executive Summary, Scope & Architecture Boundaries

### 1.1 Purpose
Milestone M8 delivers native Linux desktop integration for the BornoMala Bangla Input Platform. In strict adherence to [`ROADMAP.md`](file:///e:/Codes/Bangla%20Input%20Platform/Borno%20V1/ROADMAP.md), M8 reuses the existing pure Rust core (`crates/bornomala-core`) and its stable C-ABI ([`bornomala.h`](file:///e:/Codes/Bangla%20Input%20Platform/Borno%20V1/crates/bornomala-core/include/bornomala.h)) without altering shared language logic, renaming internal `borno_*` symbols, or introducing unnecessary IPC daemons.

The Linux adapter is implemented as a native C++ Fcitx 5 addon engine (`bornomala.so`) that loads in-process into the Fcitx 5 daemon. This milestone covers key mapping from Linux XKB events and hardware keycodes, per-input-context composition lifecycle, candidate display via Fcitx 5's native UI, layout mode switching, headless automated verification, user-mode installation, and multi-application verification in Ubuntu 24.04 on WSL2/WSLg.

---

### 1.2 Architectural Framework Selection: Why Fcitx 5?

| Evaluation Dimension | Fcitx 5 (Selected) | IBus (Alternative) | Architectural Justification for BornoMala |
|:---|:---|:---|:---|
| **Plugin Architecture** | Modular C++ plugin architecture (`fcitx::InputMethodEngineV2`). | GObject/C engine running as a standalone daemon communicating via DBus. | Fcitx 5 loads `bornomala.so` directly into the daemon process. The C++ adapter statically links `libbornomala_core.a` in-process, eliminating an extra process boundary and IPC layer between the adapter and the language core. *(Note: Application-to-Fcitx communication still uses standard Wayland/X11 protocols).* |
| **Wayland & Display Protocols** | Native, first-class implementation of `wayland-text-input-v3` and `input-method-v2`. | Historically oriented around X11; Wayland behavior varies significantly across compositors. | Provides identical text input semantics across modern Wayland environments and X11/Xwayland. |
| **Candidate Window Rendering** | Fcitx 5 renders candidate popups natively using desktop shell theming (Classic UI, Kimpanel). | Engines often require custom panel painting or external panel helpers. | Zero custom X11/Wayland window painting required in the addon; candidate list is delegated to the desktop environment. |
| **Target Distribution Alignment** | Supported and readily packaged across Ubuntu 24.04 LTS, Debian 12+, Fedora, Arch Linux, and SteamOS. | Default on GNOME desktop, but complex for headless testing and custom modular plugins. | Standard `extra-cmake-modules` and `libfcitx5core-dev` headers provide stable, versioned C++ APIs. |

## 3. Key Representations & Physical/Logical Mapping Contracts

### 3.1 The Borno Physical Key Model
In `bornomala-core`, fixed keyboard layouts (National/Jatiyo, Probhat, Bijoy) are driven by the ANSI 48-key physical layout defined in [`crates/bornomala-core/src/layout/schema.rs`](file:///e:/Codes/Bangla%20Input%20Platform/Borno%20V1/crates/bornomala-core/src/layout/schema.rs) and exposed in [`bornomala.h`](file:///e:/Codes/Bangla%20Input%20Platform/Borno%20V1/crates/bornomala-core/include/bornomala.h):

- **Exact Valid Physical Range:** `0..=47` (`BORNO_KEY_COUNT = 48`).
- **Row E (Number Row, 13 keys):** `0..=12` (`BACKQUOTE`=0, `DIGIT1`..`DIGIT0`=1..10, `MINUS`=11, `EQUAL`=12).
- **Row D (Upper Row, 13 keys):** `13..=25` (`Q`..`P`=13..22, `BRACKET_LEFT`=23, `BRACKET_RIGHT`=24, `BACKSLASH`=25).
- **Row C (Home Row, 11 keys):** `26..=36` (`A`..`L`=26..34, `SEMICOLON`=35, `QUOTE`=36).
- **Row B (Bottom Row, 10 keys):** `37..=46` (`Z`..`M`=37..43, `COMMA`=44, `PERIOD`=45, `SLASH`=46).
- **Row A (Space Row, 1 key):** `47` (`SPACE`=47).

> [!IMPORTANT]
> **Physical Keys vs. Action Events:**
> 1. In `bornomala-core`, physical key codes `0..=47` represent character-producing keyboard switches.
> 2. `Backspace`, `Enter`, `Tab`, and `Escape` are **not** physical keys in `0..=47`. They are distinct C-ABI action events (`BORNO_EVENT_BACKSPACE`, `BORNO_EVENT_COMMIT`, `BORNO_EVENT_CANCEL`) or application passthrough events.
> 3. `Space` is unique: it is both a physical key (`BORNO_KEY_SPACE = 47`) and an action that commits compositions in phonetic and fixed layout engines.

### 3.2 Key Representation in Fcitx 5

Fcitx 5 provides three distinct views of each key event in `fcitx::KeyEvent`. Because Fcitx development headers are not yet installed in the target WSL2 environment, these API signatures are based on upstream Fcitx 5 documentation and remain **UNRESOLVED on the target machine** until Stage 3A header compilation and Stage 1 test harness execution:

1. **`keyEvent.key()` (Normalized KeySyms):**
   - Returns `fcitx::Key` representing the logical keysym after XKB processing and modifier normalization.
   - For letters, uppercase Shift is normalized away from the state flag (e.g. `XKB_KEY_A` is emitted).
   - `fcitx::Key::keySymToUnicode(key.sym())` converts the keysym directly to its Unicode character (`'a'`, `'A'`, `'1'`, `'!'`).
   - **Intended Specification (UNRESOLVED on target machine):** Logical-character ingestion in Phonetic mode via `BORNO_EVENT_INPUT_CHAR`.
2. **`keyEvent.rawKey()` (Raw Key & Modifiers):**
   - Returns the key event prior to internal modifier normalization.
   - `rawKey().states()` preserves the exact hardware modifier flags (including `Shift` and `AltGr`).
   - **Intended Specification (UNRESOLVED on target machine):** Accurate modifier extraction for all modes (`ExtractBornoModifiers(keyEvent.rawKey().states())`).
3. **`keyEvent.origKey()` (Hardware Scancodes):**
   - Returns the original platform key event received from the Wayland/X11 frontend.
   - `origKey().code()` returns the platform keycode (`evdev scancode + 8` in standard XKB).
   - **Intended Specification (UNRESOLVED on target machine):** Physical keycode extraction for Fixed layouts (National, Probhat, Bijoy) via `EvdevToBornoPhysicalKey()`.

### 3.3 Phonetic vs. Fixed Mapping Strategies

#### A. Phonetic Mode (Logical-Character Ingestion)
- Phonetic input transliterates Latin letters to Bangla based on English characters (`ami` -> `আমি`).
- The adapter translates `keyEvent.key().sym()` to a Unicode scalar value using `fcitx::Key::keySymToUnicode(sym)`.
- **Letters & Case Sensitivity:** Uppercase letters (`T`, `D`, `R`, `S`, `Z`, etc.) produce distinct consonants (`ট`, `ড`, `ড়`, `শ`, `য`) via `BORNO_EVENT_INPUT_CHAR` and are never downcased.
- **Punctuation:** Printable ASCII punctuation (`.`, `,`, `?`, `!`, `-`, `/`, etc.) is passed to the engine and tokenizer via `BORNO_EVENT_INPUT_CHAR`.
- **Unsupported / Dead Keys:** Non-ASCII keysyms or dead keys lacking printable Unicode mapping return from `keyEvent()` unconsumed, allowing client applications to handle them.

#### B. Fixed Layout Modes (Three-Layer Physical Key Architecture)
Fixed layouts (National, Probhat, Bijoy) depend on physical key positions. The design distinguishes three separate layers:
1. **Platform Hardware Scancode Extraction:**
   - Linux evdev drivers typically offset keycodes by 8 (`xkb_keycode = evdev_scancode + 8`).
   - The adapter derives: `uint32_t scancode = (raw_code >= 8) ? (raw_code - 8) : raw_code;`.
   - **Status:** **UNRESOLVED on WSLg** pending Stage 1 runtime logging to confirm Microsoft WSLg Wayland compositor scancode behavior.
2. **ANSI Physical Key Lookup Table (`EvdevToBornoPhysicalKey`):**
   - A static 48-entry lookup table mapping Linux evdev scancodes (`KEY_GRAVE=41` .. `KEY_SPACE=57`) to Borno physical keys `0..=47`.
   - **Status:** **SOURCE-VERIFIED** against `<linux/input-event-codes.h>` and `PhysicalKey::ALL`.
3. **Alternative Desktop Layout Compatibility:**
   - In Fixed modes, hardware scancodes map to ANSI positions regardless of host OS layout (Dvorak, Colemak, AZERTY).
   - In Phonetic mode, logical keysyms follow the software layout (e.g. typing on Dvorak transliterates Dvorak characters).
   - **Status:** **UNRESOLVED** pending Stage 1 test harness execution with simulated non-US keymaps.

### 5.3 Three-Way C-ABI Result Contract & Memory Safety Rules

To maintain strict contract consistency across §5.3, §6.1, and §6.2, every call to `borno_engine_process_key()` and `borno_engine_process_event()` must adhere to three mutually exclusive result categories:

```
┌─────────────────────────────────────────────────────────────────────────────────┐
│                           THREE-WAY C-ABI RESULT CONTRACT                       │
├───────────────────────┬─────────────────────────────────────────────────────────┤
│ Category A:           │ Condition: rc != BORNO_OK (Negative error code)          │
│ C-ABI Engine Error    │ • Output Inspection: NEVER inspect out_result fields.   │
│                       │ • Cached State: Context prop state is NOT mutated.      │
│                       │ • UI Changes: Preedit and input panel remain UNTOUCHED. │
│                       │ • Key Consumption: Consumed (filterAndAccept()) to      │
│                       │   prevent leaking raw keys or corrupting host app.      │
│                       │ • Memory: Call borno_process_result_free_members(&res). │
├───────────────────────┼─────────────────────────────────────────────────────────┤
│ Category B:           │ Condition: rc == BORNO_OK && !res.handled                │
│ Successful Unhandled  │ • Output Inspection: Valid struct, but handled is false. │
│                       │ • Cached State: Context prop state is NOT mutated.      │
│                       │ • UI Changes: Preedit and input panel remain UNTOUCHED. │
│                       │ • Key Consumption: NOT consumed (return;), allowing     │
│                       │   the host application to process the key natively.     │
│                       │ • Memory: Call borno_process_result_free_members(&res). │
├───────────────────────┼─────────────────────────────────────────────────────────┤
│ Category C:           │ Condition: rc == BORNO_OK && res.handled                 │
│ Successful Handled    │ • Text Delivery: ic->commitString(res.committed_text).  │
│                       │ • Cached State: prop->syncFromState(res.state).         │
│                       │ • UI Changes: Refreshes preedit underline & candidates. │
│                       │ • Key Consumption: Consumed (filterAndAccept()).        │
│                       │ • Memory: Call borno_process_result_free_members(&res). │
└───────────────────────┴─────────────────────────────────────────────────────────┘
```

#### Detailed Memory Management Rules:
1. **Zero Initialization:** The caller must zero-initialize `BornoProcessResultC` (`BornoProcessResultC res{};`) or `BornoStateC` before passing pointers to C-ABI functions.
2. **Error Code Checking:** If `rc != BORNO_OK`, output structs must NOT be inspected for string contents or candidate counts; call `borno_process_result_free_members(&res)` and abort processing.
3. **Deep Copy Before Cleanup:** Extract all required strings into `std::string` / `std::vector<std::string>` before invoking `borno_process_result_free_members(&res)`.
4. **Exactly-Once Cleanup:** Cleanup functions free all inner allocations and set pointers to `nullptr`. Must be called on every path via RAII scope guard (`ScopedProcessResult`).

## 6. Authoritative Key-Event Dispatch Flow & Lifecycle Matrix

### 6.1 Authoritative Dispatch Pipeline in `keyEvent()`

The adapter enforces this strict, single dispatch flow:

```cpp
void BornoMalaEngine::keyEvent(const fcitx::InputMethodEntry& entry, fcitx::KeyEvent& keyEvent) {
    // -------------------------------------------------------------------------
    // STEP 1: Filter Key Releases
    // -------------------------------------------------------------------------
    if (keyEvent.isRelease()) {
        return; // Early return, unconsumed: let OS/app handle key releases
    }

    // -------------------------------------------------------------------------
    // STEP 2: Filter Pure Modifier Keystrokes
    // -------------------------------------------------------------------------
    if (fcitx::Key::isModifier(keyEvent.key().sym())) {
        return; // Early return, unconsumed: Shift, Ctrl, Alt, Super, CapsLock
    }

    // -------------------------------------------------------------------------
    // STEP 3: Pass Through Application Accelerators
    // -------------------------------------------------------------------------
    const auto& states = keyEvent.rawKey().states();
    if ((states.test(fcitx::KeyState::Ctrl) || states.test(fcitx::KeyState::Alt)) &&
        !states.test(fcitx::KeyState::AltGr)) {
        return; // Early return, unconsumed: Ctrl+C, Ctrl+V, Alt+F4, etc.
    }

    // -------------------------------------------------------------------------
    // STEP 4: Global Mode Switch Key (F12)
    // Policy: ONLY pure, unmodified F12 toggles mode.
    // Any modified F12 (Shift+F12, Ctrl+F12, Alt+F12, Super+F12) is an application
    // or desktop shortcut (e.g. IDE debug step, DevTools) and passes through unconsumed.
    // -------------------------------------------------------------------------
    if (keyEvent.key().sym() == XKB_KEY_F12) {
        if (states.test(fcitx::KeyState::Shift) ||
            states.test(fcitx::KeyState::Ctrl) ||
            states.test(fcitx::KeyState::Alt) ||
            states.test(fcitx::KeyState::Super)) {
            return; // Explicit pass-through: modified F12 reaches application unconsumed
        }

        auto* ic = keyEvent.inputContext();
        auto* prop = ic->propertyFor(&m_factory);
        auto* engine = prop->engine();
        int32_t currentMode = prop->contextMode();

        int32_t nextMode;
        switch (currentMode) {
            case BORNO_MODE_PHONETIC:       nextMode = BORNO_MODE_FIXED_NATIONAL; break;
            case BORNO_MODE_FIXED_NATIONAL: nextMode = BORNO_MODE_FIXED_PROBHAT;  break;
            case BORNO_MODE_FIXED_PROBHAT:  nextMode = BORNO_MODE_FIXED_BIJOY;    break;
            case BORNO_MODE_FIXED_BIJOY:    nextMode = BORNO_MODE_PASSTHROUGH;     break;
            case BORNO_MODE_PASSTHROUGH:    nextMode = BORNO_MODE_PHONETIC;       break;
            default:                        nextMode = BORNO_MODE_PHONETIC;       break;
        }

        BornoEventC ev{};
        ev.event_type = BORNO_EVENT_SWITCH_MODE;
        ev.mode_payload = nextMode;

        BornoProcessResultC res{};
        int32_t rc = borno_engine_process_event(engine, &ev, &res);
        if (rc == BORNO_OK && res.handled) {
            prop->setContextMode(nextMode);
            m_globalMode = nextMode;
            syncContextAndUI(ic, prop, res);
        }
        borno_process_result_free_members(&res);
        keyEvent.filterAndAccept();
        return;
    }

    auto* ic = keyEvent.inputContext();
    auto* prop = ic->propertyFor(&m_factory);
    auto* engine = prop->engine();
    int32_t currentMode = prop->contextMode();

    // -------------------------------------------------------------------------
    // STEP 5: English Passthrough Mode
    // All non-F12 keys pass through to application completely unconsumed.
    // -------------------------------------------------------------------------
    if (currentMode == BORNO_MODE_PASSTHROUGH) {
        return; // Unconsumed: ordinary English typing reaches app directly
    }

    // -------------------------------------------------------------------------
    // STEP 6: Active Composition Dispatch (state.is_composing == true)
    // -------------------------------------------------------------------------
    if (prop->isComposing()) {
        auto sym = keyEvent.key().sym();

        // 6A. Cancel: Escape
        if (sym == XKB_KEY_Escape) {
            BornoEventC ev{};
            ev.event_type = BORNO_EVENT_CANCEL;
            BornoProcessResultC res{};
            int32_t rc = borno_engine_process_event(engine, &ev, &res);
            if (rc == BORNO_OK && res.handled) {
                syncContextAndUI(ic, prop, res);
            }
            borno_process_result_free_members(&res);
            keyEvent.filterAndAccept();
            return;
        }

        // 6B. Commit: Return / KP_Enter
        if (sym == XKB_KEY_Return || sym == XKB_KEY_KP_Enter) {
            BornoEventC ev{};
            ev.event_type = BORNO_EVENT_COMMIT;
            BornoProcessResultC res{};
            int32_t rc = borno_engine_process_event(engine, &ev, &res);
            if (rc == BORNO_OK && res.handled) {
                syncContextAndUI(ic, prop, res);
            }
            borno_process_result_free_members(&res);
            keyEvent.filterAndAccept();
            return;
        }

        // 6C. Space: Commit + Space
        if (sym == XKB_KEY_space) {
            BornoProcessResultC res{};
            int32_t rc;
            if (currentMode == BORNO_MODE_PHONETIC) {
                BornoEventC ev{};
                ev.event_type = BORNO_EVENT_INPUT_CHAR;
                ev.char_codepoint = ' ';
                rc = borno_engine_process_event(engine, &ev, &res);
            } else {
                rc = borno_engine_process_key(engine, BORNO_KEY_SPACE, 0, &res);
            }
            if (rc == BORNO_OK && res.handled) {
                syncContextAndUI(ic, prop, res);
            }
            borno_process_result_free_members(&res);
            keyEvent.filterAndAccept();
            return;
        }

        // 6D. Candidate Navigation: Up / Down Arrows (Phonetic Only)
        if (currentMode == BORNO_MODE_PHONETIC && prop->candidatesCount() > 0) {
            if (sym == XKB_KEY_Down || sym == XKB_KEY_Up) {
                BornoEventC ev{};
                ev.event_type = (sym == XKB_KEY_Down) ? BORNO_EVENT_NEXT_CANDIDATE : BORNO_EVENT_PREV_CANDIDATE;
                BornoProcessResultC res{};
                int32_t rc = borno_engine_process_event(engine, &ev, &res);
                if (rc == BORNO_OK && res.handled) {
                    syncContextAndUI(ic, prop, res);
                }
                borno_process_result_free_members(&res);
                keyEvent.filterAndAccept();
                return;
            }
        }

        // 6E. Candidate Digit Shortcuts: Pure Unmodified Main-Row '1'..'9' (Phonetic Only)
        // Policy: ONLY pure, unshifted main-row number keys select candidates.
        // Shift+1 ('!'), AltGr+digit, Ctrl+digit, Super+digit, and Keypad digits must NEVER trigger candidate selection.
        if (currentMode == BORNO_MODE_PHONETIC && prop->candidatesCount() > 0 &&
            !states.test(fcitx::KeyState::Shift) &&
            !states.test(fcitx::KeyState::AltGr) &&
            !states.test(fcitx::KeyState::Ctrl) &&
            !states.test(fcitx::KeyState::Alt) &&
            !states.test(fcitx::KeyState::Super) &&
            sym >= XKB_KEY_1 && sym <= XKB_KEY_9) {
            size_t candIdx = static_cast<size_t>(sym - XKB_KEY_1);
            if (candIdx < prop->candidatesCount()) {
                selectCandidateByIndex(ic, prop, candIdx);
                keyEvent.filterAndAccept();
                return;
            }
            // Out-of-range main-row digit falls through to 6H character ingestion
        }

        // 6F. Backspace
        if (sym == XKB_KEY_BackSpace) {
            BornoEventC ev{};
            ev.event_type = BORNO_EVENT_BACKSPACE;
            BornoProcessResultC res{};
            int32_t rc = borno_engine_process_event(engine, &ev, &res);
            if (rc == BORNO_OK && res.handled) {
                syncContextAndUI(ic, prop, res);
            }
            borno_process_result_free_members(&res);
            keyEvent.filterAndAccept();
            return;
        }

        // 6G. Cursor Movement: Left / Right Arrows
        if (sym == XKB_KEY_Left || sym == XKB_KEY_Right) {
            BornoEventC ev{};
            ev.event_type = (sym == XKB_KEY_Left) ? BORNO_EVENT_MOVE_CURSOR_LEFT : BORNO_EVENT_MOVE_CURSOR_RIGHT;
            BornoProcessResultC res{};
            int32_t rc = borno_engine_process_event(engine, &ev, &res);
            if (rc == BORNO_OK && res.handled) {
                syncContextAndUI(ic, prop, res);
            }
            borno_process_result_free_members(&res);
            keyEvent.filterAndAccept();
            return;
        }

        // 6H. Character Ingestion by Mode
        if (ingestCharacter(ic, prop, keyEvent, currentMode)) {
            keyEvent.filterAndAccept();
            return;
        }

        // Other non-character keys pass through
        return;
    }

    // -------------------------------------------------------------------------
    // STEP 7: Idle (Not Composing) Key Dispatch
    // -------------------------------------------------------------------------
    if (ingestCharacter(ic, prop, keyEvent, currentMode)) {
        keyEvent.filterAndAccept();
        return;
    }

    // All other keys pass through to application
    return;
}
```

### 6.2 State Synchronization & Context Management

```cpp
void BornoMalaEngine::syncContextAndUI(fcitx::InputContext* ic, BornoContextState* prop, const BornoProcessResultC& res) {
    if (!res.handled) {
        return;
    }

    // Deliver committed text if any
    if (res.committed_text != nullptr && res.committed_text[0] != '\0') {
        ic->commitString(res.committed_text);
    }

    // Synchronize cached property state
    prop->syncFromState(res.state);

    if (res.state.is_composing) {
        fcitx::Text preeditText;
        preeditText.append(res.state.preedit, fcitx::TextFormatFlag::Underline);
        preeditText.setCursor(CodepointToByteOffset(res.state.preedit, res.state.cursor_pos));

        if (ic->capabilityFlags().test(fcitx::CapabilityFlag::Preedit)) {
            ic->inputPanel().setClientPreedit(preeditText);
        } else {
            ic->inputPanel().setPreedit(preeditText);
        }
        ic->updatePreedit();

        // Candidates apply to Phonetic mode only (evaluated against resulting core mode)
        if (res.state.mode == BORNO_MODE_PHONETIC && res.state.candidates_count > 0) {
            updateCandidateListUI(ic, res.state);
        } else {
            ic->inputPanel().reset();
            ic->updateUserInterface(fcitx::UserInterfaceComponent::InputPanel);
        }
    } else {
        ic->inputPanel().reset();
        ic->updatePreedit();
        ic->updateUserInterface(fcitx::UserInterfaceComponent::InputPanel);
    }
}

void BornoMalaEngine::selectCandidateByIndex(fcitx::InputContext* ic, BornoContextState* prop, size_t index) {
    auto* engine = prop->engine();
    BornoEventC ev{};
    ev.event_type = BORNO_EVENT_SELECT_CANDIDATE;
    ev.index_payload = index;

    BornoProcessResultC res{};
    int32_t rc = borno_engine_process_event(engine, &ev, &res);
    if (rc == BORNO_OK && res.handled) {
        syncContextAndUI(ic, prop, res);
    }
    borno_process_result_free_members(&res);
}

bool BornoMalaEngine::ingestCharacter(fcitx::InputContext* ic, BornoContextState* prop, fcitx::KeyEvent& keyEvent, int32_t currentMode) {
    auto* engine = prop->engine();
    BornoProcessResultC res{};
    int32_t rc = BORNO_ERR_INVALID_ARGUMENT;

    if (currentMode == BORNO_MODE_PHONETIC) {
        uint32_t sym = keyEvent.key().sym();
        uint32_t unicode = fcitx::Key::keySymToUnicode(sym);
        if (unicode == 0) {
            return false; // Non-printable / dead key passes through unconsumed
        }
        BornoEventC ev{};
        ev.event_type = BORNO_EVENT_INPUT_CHAR;
        ev.char_codepoint = unicode;
        rc = borno_engine_process_event(engine, &ev, &res);
    } else {
        // Fixed layout modes (National, Probhat, Bijoy)
        uint32_t raw_code = keyEvent.origKey().code();
        uint32_t scancode = (raw_code >= 8) ? (raw_code - 8) : raw_code;
        int32_t phys_key = EvdevToBornoPhysicalKey(scancode);
        if (phys_key < 0 || phys_key >= BORNO_KEY_COUNT) {
            return false; // Key not in ANSI 48-key matrix passes through unconsumed
        }
        uint32_t mods = ExtractBornoModifiers(keyEvent.rawKey().states());
        rc = borno_engine_process_key(engine, static_cast<uint32_t>(phys_key), mods, &res);
    }

    bool accepted = false;
    if (rc == BORNO_OK && res.handled) {
        syncContextAndUI(ic, prop, res);
        accepted = true;
    }
    borno_process_result_free_members(&res);
    return accepted;
}
```

### 6.3 Lifecycle Management, Context Isolation & UI Suppression Policy

Fcitx 5 manages multiple input contexts (`fcitx::InputContext`), one for each active application window or input field. The engine enforces strict state isolation, mode preservation, and UI suppression rules:

#### 1. Explicit Client Reset (`reset()`):
- **Trigger:** Invoked when the client application signals that the cursor moved (e.g. mouse click elsewhere in text, arrow navigation outside the IME, or focus change within the same document).
- **Engine Action:** Calls `borno_engine_reset(engine, &out_state)`. The provisional composition buffer is **DISCARDED**.
- **Mode Preservation:** `borno_engine_reset()` **strictly preserves the active input mode** (`state.mode` remains unchanged).
- **UI Action:** `ic->inputPanel().reset()` immediately closes the candidate window and `ic->updatePreedit()` clears the inline preedit.

#### 2. Context Deactivation (`deactivate()`):
- **Trigger:** Invoked when an input context loses active focus, the window blurs, or the IME is temporarily bypassed. Note: `deactivate()` does NOT imply application termination or context destruction.
- **Engine Action:** If `is_composing == true`, the provisional composition is discarded via `borno_engine_reset()` to prevent orphaned composition buffers from persisting or leaking into other applications.
- **Mode Preservation:** The context's selected layout mode is **strictly preserved**.
- **UI Suppression (Stale UI Prevention):** `ic->inputPanel().reset()` is called immediately to guarantee no orphaned or floating candidate windows remain rendered on the desktop.

#### 3. Context Activation (`activate()`):
- **Trigger:** Invoked when an application window or input field gains focus.
- **Idle State (`is_composing == false`):** Context mode is synchronized with the addon's `m_globalMode`. Preedit and candidate UI are reset.
- **Composing State (`is_composing == true`):** If an uncommitted composition was preserved, active preedit and candidate lists are restored to the input panel without altering context mode.

#### 4. Multi-Context Switching & Global Mode Continuity:
- Each `fcitx::InputContext` holds its own `BornoContextState` via `propertyFor(&m_factory)`, containing an independent `BornoEngineHandle*`.
- When the user presses `F12` in App A, `m_globalMode` is updated. When App B is activated while idle, it lazily synchronizes its mode to `m_globalMode`, providing a seamless global typing mode across applications without corrupting any context's active buffer.

| Scenario | Triggering Fcitx Callback | Engine State Action | Text Committed? | Preedit & Candidate UI | Mode Effect |
|:---|:---|:---|:---|:---|:---|
| **Activation (Idle)** | `activate()` | Sync context mode with `m_globalMode`. | None | Reset input panel (`ic->inputPanel().reset()`). | Updated to `m_globalMode` |
| **Activation (Composing)** | `activate()` | Retain active composition buffer. | None | Restore preedit and candidate UI. | Retained |

## 7. Preedit, Cursor, and UTF-8 Conversion Contract

### 7.1 Invariant, Units, and Validated Codepoint-to-Byte Conversion
- **Rust Core Invariant (SOURCE-VERIFIED):** Rust `String` (`state.preedit`) is guaranteed valid UTF-8 by core construction.
- **Core Cursor Unit (SOURCE-VERIFIED):** Core indexes `cursor_pos` in Unicode codepoints (`char` count) via [`crates/bornomala-core/src/lib.rs`](file:///e:/Codes/Bangla%20Input%20Platform/Borno%20V1/crates/bornomala-core/src/lib.rs).
- **Fcitx 5 Cursor Unit (UNRESOLVED on target machine):** Upstream Fcitx 5 documentation specifies that `fcitx::Text::setCursor(int cursor)` expects a UTF-8 byte offset. Because Fcitx development headers are not yet installed in WSL2, this requirement is classified as **UNRESOLVED on target machine** pending Stage 3A header verification.
- **Conversion Helper Precondition:** `CodepointToByteOffset` has a strict precondition that `utf8_str` is valid UTF-8. It iterates sequence boundaries, converting codepoint count to byte offset:

```cpp
// Precondition: utf8_str is valid UTF-8 (guaranteed by bornomala-core Rust String invariant).
size_t CodepointToByteOffset(const std::string& utf8_str, size_t codepoint_idx) {
    if (codepoint_idx == 0 || utf8_str.empty()) {
        return 0;
    }
    size_t cp = 0;
    size_t byte_idx = 0;
    const size_t len = utf8_str.size();
    while (byte_idx < len && cp < codepoint_idx) {
        unsigned char c = static_cast<unsigned char>(utf8_str[byte_idx]);
        if (c < 0x80) {
            byte_idx += 1;
        } else if ((c & 0xE0) == 0xC0 && byte_idx + 1 < len) {
            byte_idx += 2;
        } else if ((c & 0xF0) == 0xE0 && byte_idx + 2 < len) {
            byte_idx += 3;
        } else if ((c & 0xF8) == 0xF0 && byte_idx + 3 < len) {
            byte_idx += 4;
        } else {
            // Malformed UTF-8 byte encountered: clamp safely
            return byte_idx;
        }
        cp++;
    }
    return std::min(byte_idx, len);
}
```

### 7.2 Unicode Boundary Test Specifications
The following conversion unit tests will be executed in Layer 4 (`test_engine_adapter`):
1. **Empty String:** `""`, `cursor_pos = 0` -> Byte offset `0`.
2. **ASCII String:** `"ami"`, `cursor_pos = 0` -> `0`; `cursor_pos = 2` -> `2`; `cursor_pos = 3` -> `3`.
3. **Single Bengali Character:** `"ক"` (U+0995, 3 bytes: `E0 A6 95`), `cursor_pos = 0` -> `0`; `cursor_pos = 1` -> Byte offset `3`.
4. **Consonant + Dependent Vowel Sign:** `"কা"` (`ক` U+0995 + `া` U+09BE, 6 bytes), `cursor_pos = 1` -> Byte offset `3`; `cursor_pos = 2` -> Byte offset `6`.
5. **Virama Conjunct Sequence:** `"ক্ষ"` (`ক` U+0995 + `্` U+09CD + `ষ` U+09B7, 9 bytes), `cursor_pos = 0` -> `0`; `cursor_pos = 1` -> `3`; `cursor_pos = 2` -> `6`; `cursor_pos = 3` -> Byte offset `9`.
6. **Complex Cluster with Matras:** `"শ্রী"` (`শ` U+09B6 + `্` U+09CD + `র` U+09B0 + `ী` U+09C0, 12 bytes), `cursor_pos = 4` -> Byte offset `12`.
7. **End-of-String Boundary:** `"বাংলা"`, `cursor_pos = 5` -> Byte offset `15`.
8. **Out-of-Bounds Clamp:** `"কা"` (6 bytes), `cursor_pos = 99` -> Clamps safely to byte offset `6`.

## 8. Candidate List, Enter Precedence, and Digit Fallbacks

### 8.1 Candidate Selection Semantics & Fallback
1. **Highlight vs Selection:**
   - In `bornomala-core`, `state.selected_candidate_index` is `-1` (None) by default.
   - It becomes `Some(idx)` (`>= 0`) only when explicitly navigated via Up/Down arrow keys.
2. **Enter Commit Precedence:**
   - If `selected_candidate_index >= 0`: commits the highlighted candidate.
   - If `selected_candidate_index == -1` and candidates exist: core commits `candidates[0]` (the primary transliteration candidate).
   - If candidate list is empty: core commits `preedit`.
3. **Digit Shortcuts vs Fallback:**
   - In Phonetic mode, **pure unshifted main-row digits `1`..`9`** select candidate index `(digit - 1)` if `(digit - 1) < candidates_count`.
   - If out of range (`digit - 1 >= candidates_count`), the digit is ingested as a character via `BORNO_EVENT_INPUT_CHAR`.
   - In Fixed modes, candidate lists are unused (`candidates_count == 0`), and digit keys map directly to physical layout keys.
   - **Modifier & Keypad Safety:** Shifted digits (`!`, `@`, `#`), AltGr-modified digits (`AltGr+1`..`9`), Ctrl/Alt/Super combinations, and keypad digits (`KP_1`..`KP_9`) are **strictly prohibited** from selecting candidates. Keypad digits fall through to numeric character input; accelerator combinations pass through unconsumed.

### 8.2 Key Event Representation & Edge-Case Test Specifications
To be validated in Layer 3 (`test_key_mapper`) and Layer 4 (`test_engine_adapter`):
1. **Lowercase Phonetic Input:** Keystrokes `a`, `m`, `i` map to keysyms `XKB_KEY_a`, `XKB_KEY_m`, `XKB_KEY_i`, converting via `keySymToUnicode` to `'a'`, `'m'`, `'i'`, producing preedit `"আমি"`.
2. **Uppercase Phonetic Input (Case Sensitivity):** Keystrokes `T`, `D`, `R`, `S`, `Z` produce keysyms `XKB_KEY_T`, `XKB_KEY_D`, `XKB_KEY_R`, `XKB_KEY_S`, `XKB_KEY_Z`. The adapter must NOT downcase them. Core transliterates them to distinct consonants: `ট`, `ড`, `ড়`, `শ`, `য`.
3. **Shifted Punctuation Ingestion:** Shift+1 (`!`), Shift+/ (`?`), Shift+comma (`<`), Shift+period (`>`) produce printable punctuation Unicode scalars, ingested into `raw_buffer` and preedit without being dropped.
4. **AltGr Key Combinations:** `rawKey().states()` reporting `fcitx::KeyState::AltGr` is extracted via `ExtractBornoModifiers()`. Step 3 must NOT drop AltGr keys as Ctrl/Alt accelerators. In Fixed layouts (e.g. National), AltGr+4 emits `$`, AltGr+7 emits `&`.
5. **Ctrl/Alt Accelerators:** `Ctrl+C`, `Ctrl+V`, `Ctrl+Z`, `Alt+F4`, `Ctrl+Shift+T` return immediately unconsumed in Step 3, passing directly to the application.
6. **Super-Modified Keys:** `Super+Space`, `Super+1`, `Super+D` return unconsumed in Step 4 and Step 6, passing directly to the window manager / desktop environment.
7. **Candidate Digit Shortcuts vs Keypad:**
   - Active phonetic composition with 3 candidates:
     - Pure `1` -> selects candidate 0, commits candidate.
     - Pure `4` (out of range) -> ingests `'4'` as character into preedit.
     - `Shift+1` (`!`) -> ingests `'!'` into preedit; does NOT select candidate 0.
     - `AltGr+1` -> does NOT select candidate 0; passes through or maps as symbol.
     - `KP_1` (`XKB_KEY_KP_1`) -> does NOT select candidate 0; falls through to character input.
