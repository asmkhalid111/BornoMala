## 1. Milestone Metadata, Scope, Dependencies & Explicit Non-Goals

### 1.1 Purpose
Transition the Borno Bangla Input Platform from an isolated desktop sandbox application into a **true, system-wide Windows Input Method Editor (IME)** using Microsoft's modern **Text Services Framework (TSF)** (`msctf.dll`).

Milestone M7 delivers:
1. An in-process COM Dynamic Link Library (`borno_tsf.dll`) loaded by Windows TSF into target 64-bit application processes.
2. In-line text composition (`ITfComposition`) within host documents, rendering native preedit underline display attributes and caret tracking.
3. A native, non-activating floating candidate window anchored to the host application's text cursor, displaying candidates and kind badges (`Word`, `Comp`, `Corr`) powered by the M6 dictionary engine.
4. Seamless integration with the shared Rust core (`borno-core`) via the C-ABI, supporting Phonetic mode, Fixed layouts (National, Probhat, Bijoy), and English passthrough.
5. In-flight composition safety, handling focus transitions, window switching, application shutdown, and external composition termination (`OnCompositionTerminated`) without text loss or host application crashes.
6. A reproducible 6-level verification pipeline with an automated test harness for Levels 1–3, scripted registration and registry inspection for Level 4, and documented end-to-end verification in real Windows applications for Levels 5–6.

### 3.1 Source-Backed C-ABI Consumption Map
Every engine field and function consumed by the TSF adapter is grounded in `crates/borno-core/include/borno.h` and `crates/borno-core/src/ffi.rs`:

| C-ABI Field / Function | Declaration & Type | Semantic Meaning & Encoding | Ownership & Nullability | Lifetime & Cleanup |
|---|---|---|---|---|
| `borno_engine_new` | `BornoEngineHandle* ()` | Allocates a new isolated engine instance | Returns heap pointer, or `NULL` on panic | Must be freed by `borno_engine_free` |
| `borno_engine_free` | `void (BornoEngineHandle*)` | Destroys engine instance | Takes ownership; safe on `NULL` | Called in `BornoTextService` destructor |
| `borno_engine_process_key` | `int32_t (handle, vkey, mods, out_result)` | Processes ANSI key code (0..=47) and modifier bitflags | Allocates strings in `out_result` | Caller must call `borno_process_result_free_members` |
| `borno_engine_process_event` | `int32_t (handle, event, out_result)` | Processes normalized events (Backspace, Reset, Select) | Allocates strings in `out_result` | Caller must call `borno_process_result_free_members` |

### 3.2 Key Mapping & Event Dispatch Layer
Windows virtual keys (`WPARAM wParam` in `ITfKeyEventSink::OnKeyDown`) are translated to the engine via a dedicated translation table:

```
┌─────────────────────────────────┬────────────────────────────────┬──────────────────────────┐
│ Windows Keystroke (TSF)         │ Borno Engine Representation   │ Dispatch Mechanism       │
├─────────────────────────────────┼────────────────────────────────┼──────────────────────────┤
│ Alphanumeric (A-Z, 0-9)         │ BORNO_KEY_A..Z, DIGIT0..9      │ borno_engine_process_key │
│ Punctuation (OEM_1..OEM_7)      │ BORNO_KEY_SEMICOLON, etc. (0..47) borno_engine_process_key │
│ Space (VK_SPACE)                │ BORNO_KEY_SPACE (47)           │ borno_engine_process_key │
│ Backspace (VK_BACK)             │ BORNO_EVENT_BACKSPACE          │ borno_engine_process_event│
│ Delete (VK_DELETE)              │ BORNO_EVENT_DELETE             │ borno_engine_process_event│
│ Escape (VK_ESCAPE)              │ BORNO_EVENT_CANCEL             │ borno_engine_process_event│
│ Enter (VK_RETURN)               │ BORNO_EVENT_COMMIT             │ borno_engine_process_event│
│ Arrow Left / Right              │ BORNO_EVENT_MOVE_CURSOR_LEFT/RT│ borno_engine_process_event│
│ Arrow Up / Down                 │ BORNO_EVENT_PREV/NEXT_CANDIDATE│ borno_engine_process_event│
│ Candidate Digit (1-9, UI shown) │ BORNO_EVENT_SELECT_CANDIDATE   │ borno_engine_process_event│
│ Unmapped Keys (F1-F12, Home,...)│ N/A (*pfEaten = FALSE)         │ Pass-through to host     │
└─────────────────────────────────┴────────────────────────────────┴──────────────────────────┘
```

- **Modifier bitflags:** Shift (`0x01`), AltGr (`0x02`), Ctrl (`0x04`), Alt (`0x08`), queried via Win32 `GetKeyState`.

### 3.3 Unicode Conversion & Grapheme Cluster Offsets
- **UTF-8 to UTF-16 Conversion:** Windows TSF ranges operate in 16-bit code units (`wchar_t`). Conversions from Rust UTF-8 strings (`preedit`, `committed_text`) use `MultiByteToWideChar(CP_UTF8, 0, utf8_str, -1, wbuf, wbuf_len)`.
- **Caret Offset Translation:** In `borno-core`, `cursor_pos` is measured in Unicode scalar values (codepoints).
  - All standard Bengali characters (consonants, independent vowels, vowel signs, virama, nukta) reside in the Basic Multilingual Plane (`U+0980`..`U+09FF`), where 1 Unicode codepoint = 1 UTF-16 code unit.
  - For characters outside the BMP (e.g. emojis or rare symbols requiring surrogate pairs), offset mapping accumulates the exact UTF-16 code unit count (`wchar_t`) from the beginning of the preedit buffer to ensure caret positioning never splits a surrogate pair.

## 5. COM/TSF Interfaces and Lifecycle Design

### 5.1 Interface Architecture & COM Identity
`BornoTextService` implements the following standard COM and TSF interfaces:

```
┌────────────────────────────────────────────────────────────────────────┐
│                          BornoTextService                              │
├────────────────────────────────┬───────────────────────────────────────┤
│ IUnknown                       │ AddRef, Release, QueryInterface       │
│ ITfTextInputProcessor          │ Activate, Deactivate                  │
│ ITfTextInputProcessorEx        │ ActivateEx (Windows 8+ enhanced flags)│
│ ITfKeyEventSink                │ OnTestKeyDown, OnKeyDown, OnKeyUp,    │
│                                │ OnTestKeyUp, OnPreservedKey,          │
│                                │ OnSetFocus                            │
│ ITfCompositionSink             │ OnCompositionTerminated               │
│ ITfThreadMgrEventSink          │ OnInitDocumentMgr, OnSetFocus         │
│ ITfLangBarItemButton           │ Language Bar mode control button      │
└────────────────────────────────┴───────────────────────────────────────┘
```

- **COM Identity Invariant:** Querying `IID_IUnknown` on any interface exposed by `BornoTextService` must return the identical pointer value (`static_cast<ITfTextInputProcessor*>(this)`).

### 5.2 Subscription and Cleanup Lifecycle
1. **Instantiation:**
   - Host application creates `BornoTextService` via `IClassFactory::CreateInstance`.
   - Initializes COM reference count (`m_refCount = 1`) and allocates an isolated engine instance via `borno_engine_new()`.
2. **Activation (`Activate` / `ActivateEx`):**
   - Receives `ITfThreadMgr* ptim` and `TfClientId tid`.
   - Queries `ITfKeystrokeMgr` via `ptim->QueryInterface(IID_ITfKeystrokeMgr, &pKeystrokeMgr)`.
   - Calls `pKeystrokeMgr->AdviseKeyEventSink(m_clientId, static_cast<ITfKeyEventSink*>(this), TRUE)`.
   - Registers preserved hotkeys via `pKeystrokeMgr->PreserveKey`.
   - Queries `ITfSource` on `ptim` to advise `ITfThreadMgrEventSink`.
   - Instantiates and registers `ITfLangBarItemButton` with `ITfLangBarItemMgr`.
3. **Deactivation (`Deactivate`):**
   - Unregisters hotkeys via `pKeystrokeMgr->UnpreserveKey`.
   - Calls `pKeystrokeMgr->UnadviseKeyEventSink(m_clientId)`.
   - Unadvises `ITfThreadMgrEventSink`.
   - Removes Language Bar item from `ITfLangBarItemMgr`.
   - If an active composition exists (`m_pComposition != nullptr`), commits or cancels in-flight text and releases the composition.
   - Destroys floating candidate window.
   - Releases cached TSF manager pointers.
4. **Destruction:**
   - In destructor, calls `borno_engine_free(m_pEngine)` to safely deallocate the Rust engine handle.
   - Interlocked decrement of server module object count (`g_objectCount`).

### 5.3 Module Lifetime and Unload Accounting
- Standard COM server lock counting via `g_serverLocks` and `g_objectCount`.
- `DllCanUnloadNow()` returns `S_OK` if and only if `(g_serverLocks == 0 && g_objectCount == 0)`, allowing Windows to safely unload the DLL when no active host threads hold Borno instances.

## 6. Transactional Input, Edit Sessions, and Composition Lifecycle

### 6.1 The Engine-to-TSF Ordering & Transaction Problem
A critical defect in naive IME adapters is mutating the engine state before obtaining the document lock. If the document lock request is denied or delayed:
- The engine buffer advances, but the document remains unchanged.
- The next keystroke operates on corrupted engine state, producing permanent text desynchronization.

### 6.2 The Transactional Edit Solution
All engine state mutations execute **strictly inside the granted edit session callback (`DoEditSession`)**:

```
[Keystroke: OnKeyDown]
       │
       ▼
Request Synchronous Edit Session:
pic->RequestEditSession(m_clientId, pEditSession, TF_ES_READWRITE | TF_ES_SYNC, &hrSession)
       │
       ├─► [Lock Denied (TF_E_SYNCHRONOUS or TS_SD_READONLY)]
       │      ├─► Do NOT mutate engine state!
       │      ├─► Do NOT queue blind asynchronous replay!
       │      └─► Return *pfEaten = FALSE (pass key safely to host).
       │
       └─► [Lock Granted: BornoEditSession::DoEditSession(ec)]
              │
              ├─► Call borno_engine_process_key(m_pEngine, vkey, mods, &result)
              │
              ├─► Apply Document Mutations via ec:
              │      ├─ If committed_text != NULL: Replace range & EndComposition.
              │      ├─ If is_composing == true:   Update range & SetText(preedit).
              │      └─ If cancelled == true:      Clear range & EndComposition.
              │
              ├─► Set Selection Range to cursor_pos (UTF-16 code units).
              │
              ├─► Update Candidate Window (Post-Lock):
              │      └─ Show/Update candidates if count > 1; else Hide.
              │
              ├─► Store result.handled into pEditSession->m_fHandled
              │
              └─► borno_process_result_free_members(&result)
```

- **Query-Only `OnTestKeyDown`:** Must be strictly side-effect-free. Checks current mode table and active composition to return `*pfEaten = TRUE/FALSE` without mutating engine state.
- **Lock Denial Handling:** If `TF_E_SYNCHRONOUS` is returned, the engine state is never touched. Asynchronous replays are prohibited because user typing during the delay causes out-of-order execution.

### 6.3 Composition Lifecycle Matrix & Failure Recovery

| Lifecycle Event | Host Document Action in `DoEditSession(ec)` | Engine Action | Candidate Window Action | Document Operation Failure Recovery |
|---|---|---|---|---|
| **First Character (`is_composing = true`)** | If `m_pComposition == nullptr`: `pContextComposition->StartComposition(ec, pRange, this, &m_pComposition)`. Replace range with `preedit` (UTF-16). Apply `TF_ATTR_INPUT` underline attribute. Set selection to `cursor_pos`. | Advances preedit buffer | Anchors window beneath caret; shows candidates if `count > 1` | If `StartComposition` fails: reset engine via `borno_engine_reset`, return `*pfEaten = FALSE` (pass key to host). If `SetText` fails: abort composition, reset engine, hide UI. |
| **Subsequent Character** | Update existing composition range with `preedit` (UTF-16). Re-apply underline attribute. Update selection caret. | Updates preedit buffer | Updates candidate list and kind badges | If `SetText` fails: call `m_pComposition->EndComposition(ec)`, reset engine, hide UI. |
| **Space / Enter Commit** | `pCompositionRange->SetText(ec, 0, committed_text, len)`. Remove underline attributes. Call `m_pComposition->EndComposition(ec)`. Release `m_pComposition = nullptr`. | Emits `committed_text`, `is_composing = false` | Hides candidate window immediately | If `SetText` or `EndComposition` fails: force release `m_pComposition = nullptr`, reset engine to idle. |
| **Fixed Layout Direct Output** | If `m_pComposition == nullptr`: Insert `committed_text` directly at current document selection range. Move selection to end of inserted text. | Emits `committed_text`, `is_composing = false` | Stays hidden (`candidates_count == 0`) | If `SetText` fails: pass key through to host. |

| **Explicit Cancel (`Esc`)** | Replace composition range with empty string `L""` (length 0). Call `m_pComposition->EndComposition(ec)`. Release `m_pComposition = nullptr`. | Resets preedit and candidates | Hides candidate window immediately | Force release `m_pComposition = nullptr`, reset engine. |
| **External Termination (`OnCompositionTerminated`)** | None. Document has already been modified/cleared by the host application. **Strictly avoid calling `EndComposition`**. | Call `borno_engine_reset(m_pEngine, &state)` | Release `m_pComposition = nullptr`; hide candidate window | N/A (zero document mutation performed). |
| **Focus Loss (`OnSetFocus(FALSE)`)** | If `m_pComposition != nullptr`: Check `auto_commit_on_mode_switch`. If true, commit preedit and `EndComposition`. If false, set text to `L""` and `EndComposition`. | Reset or commit per config | Hide candidate window | If commit fails: reset engine, release composition. |
| **Read-Only Document** | Query `pic->GetStatus(&docStatus)`. If `TS_SD_READONLY`, abort edit session. Return `*pfEaten = FALSE`. | Zero state mutation | Stays hidden | N/A |
| **Mode Switch During Composition** | Respects `auto_commit_on_mode_switch`: commits active preedit if true, cancels if false. Ends composition before switching mode. | Switches active mode table | Hides candidate window | If commit fails: cancel and reset engine. |

#### Engine/Document State Reconciliation Invariant
`borno-core` does not support arbitrary backward snapshots/rollbacks. Therefore, on any fatal TSF document mutation failure:
1. Borno **never silently continues with desynchronized engine state**.
2. It executes an atomic reset policy: invokes `borno_engine_reset(m_pEngine, &state)` to reset raw buffer, preedit, and candidate lists to clean idle state.
3. Releases `m_pComposition = nullptr` and hides the candidate window.
4. Prevents duplicate text, ghost preedits, or corrupted subsequent keystrokes.

## 7. Phonetic, Fixed-Layout, and English Mode Semantics

### 7.1 Mode Routing Invariants
The engine supports three primary mode categories:
1. **Phonetic Mode (Avro-Compatible):**
   - Intercepts alphanumeric keys and mapped punctuation.
   - Composition is active (`is_composing = true`); preedit is rendered in-line with underlines.
   - Predictive dictionary produces candidate suggestions displayed in the floating candidate window.
   - Space, Enter, or digit selection commits text and closes composition.
2. **Fixed Layout Modes (National, Probhat, Bijoy):**
   - Intercepts mapped ANSI keys (48 keys).
   - In standard typing, fixed layouts produce direct output (`committed_text != NULL`, `is_composing = false`). Text is inserted immediately at the selection.
   - When a link key (Hasanta `্`) is typed, the layout enters link-pending state (`is_composing = true`). Composition starts to hold the Hasanta until the subsequent consonant resolves the conjunct.
   - Unmapped keys (function keys, navigation arrows) pass through untouched (`*pfEaten = FALSE`).
3. **English Passthrough Mode:**
   - **Zero interception:** All alphanumeric keys, symbols, spaces, backspaces, and punctuation pass untouched (`*pfEaten = FALSE`).
   - Only the preserved mode-toggle hotkey is intercepted.
   - Zero composition overhead, allowing native English typing at host speed.

## 8. Candidate Window and Candidate Selection

### 8.1 Window Class & Non-Activation Invariant
```cpp
HWND hwnd = CreateWindowExW(
    WS_EX_TOPMOST | WS_EX_TOOLWINDOW | WS_EX_NOACTIVATE,
    L"BornoCandidateWindow",
    L"",
    WS_POPUP,
    0, 0, 0, 0,
    nullptr, nullptr, g_hInst, this
);
```
- **Focus Preservation:** Must handle `WM_MOUSEACTIVATE` and return `MA_NOACTIVATE`.
- **Displaying Window:** Must call `ShowWindow(hwnd, SW_SHOWNOACTIVATE)`.
- **Click Handling:** Clicking candidate tiles commits text via a valid document edit session without stealing focus from the host application.

### 8.2 Caret Tracking & Graceful Fallback Pipeline
1. **Primary Query:** `pContextView->GetTextExt(ec, pCompositionRange, &rcCaret, &fClipped)`.
   - If successful: Position candidate window directly beneath `rcCaret.bottom`. If too close to screen bottom, position above `rcCaret.top`.
2. **Secondary Fallback:** If `GetTextExt` fails (e.g. empty document, console window, or unsupported host control):
   - Query Win32 caret position via `GetCaretPos` / `GetGUIThreadInfo`.
3. **Tertiary Fallback:** If Win32 caret fails:
   - Position candidate window at the bottom-left of the target application's active window client area.
4. **Resilience Invariant:** **Never crash, throw, or block typing** if caret coordinates cannot be obtained.

### 8.3 High-DPI Scaling & Clamping
- Uses `GetDpiForWindow(hwndHost)` (or `GetDpiForMonitor`).
- Scales base metrics (width, line heights, fonts, badge paddings) by `dpi / 96.0f`.
- Clamps window coordinates to the monitor's working area (`GetMonitorInfoW`).

### 8.4 Candidate Selection & Digit Behavior During Composition
When a digit key (`1`..`9`) is pressed:
- **Case 1: Candidate window is visible AND index `(digit - '1') < candidates_count`:**
  - Consume key (`*pfEaten = TRUE`).
  - Dispatch `BORNO_EVENT_SELECT_CANDIDATE` with `index_payload = digit - '1'`.
  - Engine commits the selected candidate and clears composition buffer (`is_composing = false`).
  - Commit text to document, end composition, and hide candidate window.
- **Case 2: Candidate window is visible BUT index `(digit - '1') >= candidates_count`:**
  - The digit is outside the candidate range.
  - Do NOT commit candidate.
  - Process digit as ordinary text input: pass to `borno_engine_process_key` (`BORNO_KEY_DIGIT1..9`).
  - In Phonetic mode, the digit enters `raw_buffer`, transliterates, and updates preedit.
- **Case 3: Candidate window is NOT visible:**
  - The digit is treated as ordinary text input via `borno_engine_process_key`.
- **Case 4: Stale Candidate List Protection:**
  - Inside `DoEditSession`, candidate count is queried live from `m_pEngine`. If `idx >= live_count`, the selection request is rejected, preventing selection of phantom or stale candidates.
- **Badge Rendering:** Render textual badges (`Word`, `Comp`, `Corr`) with clean contrast colors. Do not require emoji rendering or specific optional fonts for functional acceptance.

## 10. Registration, Rollback, and Unregistration

### 10.1 Language Identifiers & Purpose
- **`0x0845`:** `LANG_BENGALI`, `SUBLANG_BENGALI_BANGLADESH` (Primary profile registration).
- **`0x0445`:** `LANG_BENGALI`, `SUBLANG_BENGALI_INDIA` (Secondary profile alias registered so users on Windows installations configured with "Bengali (India)" can see and select Borno in the Windows input switcher without having to install the Bangladesh language pack).

### 10.2 Registry Scope & Privilege Requirements
- **COM In-Process Server:**
  - Machine-wide: `HKEY_LOCAL_MACHINE\SOFTWARE\Classes\CLSID\{8A57F89C-3BF7-4B9E-A79B-86DF372E4F01}\InprocServer32`
  - Requires administrator elevation.
- **TSF Category & Profile:**
  - Machine-wide: `HKEY_LOCAL_MACHINE\SOFTWARE\Microsoft\CTF\TIP\{8A57F89C-3BF7-4B9E-A79B-86DF372E4F01}`
  - Managed via `ITfInputProcessorProfiles` and `ITfCategoryMgr`.
  - Requires administrator elevation.
- **Why Per-User is Insufficient for M7:** While COM allows per-user CLSIDs (`HKCU\Software\Classes\CLSID`), modern Windows TSF requires TIP profile keys under `HKLM\SOFTWARE\Microsoft\CTF\TIP` for the system input switcher to load and display keyboard TIPs. Therefore, M7 registration scripts require administrator elevation.

### 10.3 Idempotency, Rollback & Unregistration
- `DllRegisterServer()`:
  - If registration fails midway, it immediately executes internal rollback, unregistering any created keys/categories.
- `DllUnregisterServer()`:
  - Strictly deletes only keys under `{8A57F89C-3BF7-4B9E-A79B-86DF372E4F01}`.
  - Never deletes parent keys or touches other installed IMEs.
- Scripted execution:
  - `native/borno-tsf/scripts/register.bat`: Executes elevated registration via `regsvr32.exe /s`.
  - `native/borno-tsf/scripts/unregister.bat`: Executes elevated unregistration via `regsvr32.exe /u /s`.

## 11. Security, Privacy, and Process Isolation

### 11.1 Concurrency & Isolation Invariants
- **In-Process Isolation:** `borno_tsf.dll` is loaded directly into the target application's address space. Each process maintains isolated memory and independent `BornoEngineHandle` instances.
- **Thread Affinity:** COM and TSF calls occur on the host application's UI thread. Windows messages and candidate window painting are restricted to the calling thread.
- **Zero Global Mutable State:** No shared memory, cross-process mutexes, or global state across application boundaries.

### 11.2 Crash Containment & Panic Boundaries
- **Rust Panic Containment:** All Rust FFI boundaries use `std::panic::catch_unwind`. A standard panic in `borno-core` returns `BORNO_ERR_INTERNAL` rather than crashing the host process.
- **C++ Exception Containment:** All COM methods wrap native logic in `try { ... } catch (...) { return E_UNEXPECTED; }`.
- **Realistic Fault Invariant:** SEH exceptions (e.g. invalid memory access) cannot be caught by standard C++ `catch (...)`. Code must maintain pointer hygiene and bounds checking to prevent terminating the host process.

### 11.3 Offline-First Privacy Guarantee
- **Zero Telemetry:** No analytical event collection, background tracking, or network pings.
- **Zero Network Calls:** No socket creation, HTTP requests, or DNS resolutions.
- **Zero Keystroke Logging:** No raw keystroke recording, disk logging of typed characters, or preedit caching.
- **Sanitized Diagnostics:** Debug logs (if enabled during development) record only safe status identifiers, HRESULTs, and timings—never user text.

## 15. Known Risks, Unresolved Questions, and Developer Approval Gates

### 15.1 Technical Risks & Mitigations
1. **Host-Specific TSF Deficiencies:** Some third-party applications have non-compliant TSF implementations where `GetTextExt` fails.
   - *Mitigation:* Robust three-tier fallback pipeline (`GetTextExt` $\rightarrow$ `GetCaretPos` $\rightarrow$ client window lower-left corner).
2. **Elevated Privileges Requirement for Registration:** Windows requires Administrator privileges to register TSF categories under `HKLM`.
   - *Mitigation:* Automated testing (Levels 1–3) runs without elevation via `test_harness.exe`. Profile registration (Level 4) is isolated in explicit developer scripts (`register.bat`).
3. **Lock Denial During Rapid Typing:** Heavy host applications may delay or deny synchronous edit session locks.
   - *Mitigation:* Transactional edit model ensures zero engine mutation on lock denial; keystroke passes safely to host without desynchronization.

### 15.2 Unresolved Developer Decisions
1. **Default Mode Toggle Hotkey:**
   - *Option A (Recommended):* `Ctrl + \`` (Control + Grave/Backtick) — common across modern developer tools, but collides with VS Code integrated terminal.
   - *Option B:* `Ctrl + Shift + B` — mnemonic for Borno, but collides with VS Code build task and browser bookmark bar.
   - *Option C:* `F12` — classic Avro shortcut, but collides with browser DevTools and Word Save As.
2. **Secondary Language Profile (`0x0445` Bengali India):**
   - *Option A (Recommended):* Register both `0x0845` (Bangladesh) and `0x0445` (India) so users with Indian regional settings see Borno automatically.
   - *Option B:* Register `0x0845` only.
3. **Target Architecture Scope:**
   - *Option A (Recommended):* Focus M7 exclusively on native 64-bit (`x86_64`) Windows processes; defer 32-bit (`x86 WOW64`) support to M12 installer packaging.
   - *Option B:* Implement dual-architecture (x86 and x64) DLL builds immediately in M7.
