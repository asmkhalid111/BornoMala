## 1. Executive Summary & Purpose

Milestone M9 delivers comprehensive **customization, typing usability, and candidate presentation preferences** to the Borno Bangla Input Platform, transforming the solid platform foundations established in M7 (Windows TSF) and M8 (Linux Fcitx 5) into an adaptable, user-friendly typing environment.

Crucially, M9 directly resolves the **Usability and Linguistic Backlog** discovered during M8 live testing, bringing full support for standard Bengali Dáñṛi (`।`) punctuation and casual vowel ambiguity (`tomake` → `তোমাকে`).

### Core Objectives
1. **Resolve Usability & Linguistic Backlog:**
   - Correct the `0x09E4` codepoint typo in [`crates/bornomala-core/src/phonetic/tokenizer.rs`](../crates/bornomala-core/src/phonetic/tokenizer.rs) to standard Bengali Dáñṛi (`\u{0964}`).
   - Support standard Avro-style double period (`..` → `।`) tokenization in phonetic mode.
   - Add a configuration toggle for auto-converting single period (`.` → `।`).
   - Implement bounded vowel ambiguity (`o` $\leftrightarrow$ `O`) so casual lowercase typing (`tomake`) surfaces correct Bengali words (`তোমাকে`) from the embedded lexicon trie.
   - Implement post-Reph nasal homophone suggestions (`bornomala` → `বর্ণমালা`) to satisfy ণ-ত্ব বিধান without manual casing.
2. **Schema Evolution (`BornoConfig` v1.2.0):**
   - Evolve configuration schema to version `1.2.0` with strict fallback isolation and backward compatibility.
   - Add preferences for punctuation auto-conversion, candidate list orientation (`Vertical` vs `Horizontal`), font scaling, and theme selection.
3. **Configuration Import/Export & Recovery:**
   - Provide safe, validated JSON import/export mechanisms in the Tauri backend.
   - Reject invalid or corrupted imports atomically without damaging active user settings.
4. **Enhanced Settings UI:**
   - Upgrade the desktop Settings Drawer into a categorized interface:
     - **Typing & Punctuation:** Auto-Dari toggle, candidate limits, dictionary toggles.
     - **Appearance & Typography:** Theme selection (`Dark Glass`, `Light Glass`, `High Contrast`), candidate font size.
     - **Shortcuts & Layouts:** Primary toggle hotkey (`F12` / `F4`), preferred fixed layout.
     - **Backup & Reset:** Configuration export, import, and factory reset.
5. **Zero Regression Baseline:**
   - Maintain 100% pass rate across the existing 142/142 core tests and native adapter verification harnesses.

## 3. Configuration Schema Specification (`BornoConfig` v1.2.0)

### 3.1 Schema Definition in `crates/bornomala-core/src/config.rs`

```rust
/// Authoritative configuration schema for Borno (Schema Version 1.2.0).
#[derive(Debug, Clone, PartialEq, Eq, Serialize, Deserialize)]
pub struct BornoConfig {
    /// Schema format version (strictly "1.2.0" for M9).
    pub schema_version: String,

    /// Mode to initialize when the engine starts up.
    #[serde(default = "default_startup_mode")]
    pub default_startup_mode: StartupMode,

    /// Preferred fixed keyboard layout when switching to Fixed mode.
    #[serde(default = "default_preferred_fixed_layout")]
    pub preferred_fixed_layout: FixedLayoutId,

    /// Maximum number of candidates presented in candidate window (1..9, default 5).
    #[serde(default = "default_candidate_display_limit")]
    pub candidate_display_limit: usize,

    /// Auto-commit active preedit composition when switching input modes.
    #[serde(default = "default_auto_commit_on_mode_switch")]
    pub auto_commit_on_mode_switch: bool,

    // --- M6 Dictionary Assistance Settings ---
    #[serde(default = "default_enable_dictionary_assistance")]
    pub enable_dictionary_assistance: bool,

    #[serde(default = "default_enable_word_completion")]
    pub enable_word_completion: bool,

    #[serde(default = "default_max_dictionary_suggestions")]
    pub max_dictionary_suggestions: usize,

    // --- M9 Customization & Usability Additions ---
    /// Convert single ASCII full stop ('.') directly to Bengali Dáñṛi ('।') in phonetic mode.
    /// (Note: Double full stop '..' always converts to '।').
    #[serde(default = "default_auto_convert_period_to_dari")]
    pub auto_convert_period_to_dari: bool,

    /// Orientation for floating candidate presentation.
    #[serde(default = "default_candidate_orientation")]
    pub candidate_orientation: CandidateOrientation,

    /// Candidate window font size in points (10..=24, default 13).
    #[serde(default = "default_candidate_font_size")]
    pub candidate_font_size: u32,

    /// Active visual theme ID ("dark-glass", "light-glass", "high-contrast").
    #[serde(default = "default_active_theme")]
    pub active_theme: String,

    /// Preferred mode toggle key ("F12" or "F4").
    #[serde(default = "default_mode_toggle_key")]
    pub mode_toggle_key: String,
}
```

### 3.2 Invariant Validation Rules
- `schema_version`: Must equal `"1.2.0"`. Configs from `"1.0.0"` or `"1.1.0"` safely upgrade via serde defaults.
- `candidate_display_limit`: Must be between `1` and `9`.
- `max_dictionary_suggestions`: Must be between `1` and `5`.
- `candidate_font_size`: Must be between `10` and `24`.
- `active_theme`: Must be one of `["dark-glass", "light-glass", "high-contrast"]`.
- `mode_toggle_key`: Must be one of `["F12", "F4"]`.

### Phase 1: Core Punctuation Bugfix & Linguistic Backlog
- Modify [`crates/bornomala-core/src/phonetic/tokenizer.rs`](../crates/bornomala-core/src/phonetic/tokenizer.rs):
  - Replace `\u{09E4}` with `\u{0964}` (Bengali Danda / Dari `।`).
  - Replace `\u{09E5}` with `\u{0965}` (Bengali Double Danda `॥`).
  - Add `rem.starts_with("..")` handler producing `।` (`U+0964`).
  - Honor `engine.config.auto_convert_period_to_dari` when a single `.` is followed by space, punctuation, or commit.
- Modify [`crates/bornomala-core/src/dictionary/ambiguity.rs`](../crates/bornomala-core/src/dictionary/ambiguity.rs):
  - Add vowel alternation rule: rewrite inherent `o` after consonants to `O` (`o-kar`, e.g. `tomake` $\to$ `tOmake` $\to$ `তোমাকে`).
  - Add nasal alternation rule: rewrite `rn` $\to$ `rN` (`bornomala` $\to$ `borNomala` $\to$ `বর্ণমালা`).
  - Validate candidate additions against `PrefixTrie::exact_search` so only verified Bengali words enter Candidate Slot 1.
- Add unit tests in `crates/bornomala-core/tests/phonetic_tests.rs` verifying all 4 acceptance gates.

### Phase 2: Schema v1.2.0 & Import/Export in Core & Tauri
- Update `BornoConfig` in [`crates/bornomala-core/src/config.rs`](../crates/bornomala-core/src/config.rs) with new fields and default helpers.
- Implement `validate(&self) -> Result<(), ConfigValidationError>`.
- In `src-tauri/src/lib.rs`:
  - Implement `export_config() -> Result<String, String>`.
  - Implement `import_config(json_str: String) -> Result<BornoConfig, String>` with atomic validation and backup.
  - Expose IPC commands `export_config` and `import_config` to frontend.

### Phase 3: Desktop UI Categorized Settings Drawer
- Refactor [`src/components/SettingsDrawer.tsx`](../src/components/SettingsDrawer.tsx) with a modern glassmorphic tabbed navigation:
  1. **Typing & Phonetic:**
     - Auto-Dari on single period (`.` $\to$ `।`) checkbox with explanatory caption.
     - Word completion and dictionary suggestions toggles.
     - Maximum dictionary candidate limit slider (1..=5).
  2. **Appearance & Themes:**
     - Theme selector cards: `Dark Glass` (default), `Light Glass`, `High Contrast`.
     - Candidate window font size slider (10px..24px).
     - Candidate orientation selector: `Vertical` vs `Horizontal`.
  3. **Shortcuts & Keyboards:**
     - Toggle hotkey selector (`F12` vs `F4`).
     - Preferred fixed layout selector (`National`, `Probhat`, `Bijoy`).
  4. **Backup & Diagnostics:**
     - "Export Configuration (JSON)" button.
     - "Import Configuration" file picker with instant validation feedback.
     - "Restore Factory Defaults" with confirmation modal.
- Apply active theme classes to `index.css` and the virtual keyboard.

### Phase 4: Native Adapter Alignment & Regression Audit
- Ensure Windows TSF candidate window respects candidate font size and density if configured.
- Ensure Linux Fcitx 5 addon respects `F12` and `F4` hotkeys dynamically.
- Execute full test suite (`cargo test -p bornomala-core`) ensuring zero regressions.
- Validate persistence recovery with simulated malformed JSON imports.
